# Developer pages

Pages for checking the engine by hand, not part of the showcase in `examples/`. Serve the repository with `npm run serve` and open them from `http://127.0.0.1:8700/tests/pages/`:

- `portfolio/`: hover and click triggers with the page's own lines (its inline configuration is also checked against the schema).
- `esm/`: the ES module build, scripted with `init()` and the API.
- `host-compat/`: sticky navigation, forms, a modal and a button behind the character.
