Zero config

This page has exactly one line of gary.js:

<script defer src="gary.js"></script>

Gary walks in after the page has loaded. Drag him around, click him a few times, or use the ⋯ button (or right-click him) to mute or remove him.

Gary's artwork is loaded from characters/gary/ next to the script. When running this repository locally, point GARY_ASSET_DIR at a copy of the artwork, or try the custom character example.
